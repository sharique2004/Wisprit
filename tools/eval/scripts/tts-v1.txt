# tts-v1 — the synthetic corpus script for `tools/eval/corpus/tts-samantha`.
#
# TTS audio proves the harness runs end to end and catches plumbing regressions.
# It is NOT human speech and must never be quoted as an accuracy claim — every
# row it produces carries the scoreboard's TTS banner (spike S4 stays open until
# the Phase-2 human corpus lands).
#
# Format, one clip per line, six pipe-separated fields:
#
#   id | category | terms | bypass | spoken | reference
#
#   id         filename stem and manifest id
#   category   the scoreboard's per-category breakdown key
#   terms      `expect.terms` — dictionary terms that must survive to the final
#              text, semicolon-separated (empty when the clip expects none)
#   bypass     `expect.refineBypass` — the RefineOutcome this utterance must
#              leave the AI cage with (has_letter_run | has_address), or empty
#   spoken     what `say` synthesizes: the words, as a person would say them
#   reference  the text the user wanted in their document — the target for
#              EVERY stage, so raw ASR is scored against the formatting the
#              pipeline is supposed to add (see docs/eval/DEFINITIONS.md)
#
# Fields are trimmed. Double quotes and backslashes are rejected by the
# generator: the manifest is emitted with shell printf and nothing escapes them.
# When `reference` is empty the generator uses `spoken` verbatim.

# --- explicit self-correction -------------------------------------------------
# "I said the wrong day, then the right one, and only the right one lands."
# Every joint here is a CLOSED-CLASS PAIR: both sides are the same kind of thing
# (weekday, clock time, month, number), which is the only condition under which
# a weak connective — a bare "sorry", a bare "no actually" — is allowed to
# delete anything. sc-01 is the sentence the feature was asked for.
#
# sc-06 is the control and it is the important row: a weekday cannot be
# corrected into a clock time, so the joint does not type-check, so NOTHING is
# deleted and BOTH tokens survive into the reference. If sc-06's WER ever drops
# to zero by way of a deletion, the engine has started guessing.
sc-01 | self-correction |  |  | I want to have a meeting with person x on Thursday, umm, no actually Friday. | I want to have a meeting with person x on Friday.
sc-02 | self-correction |  |  | Let us move the standup to half past nine, no actually quarter past ten. | Let us move the standup to quarter past ten.
sc-03 | self-correction |  |  | The board meeting is in September, no actually October. | The board meeting is in October.
