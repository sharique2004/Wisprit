# category: postal-address

# Street addresses. Separate from 06-addresses because they exercise a different
# assertion for the same reason: `expect.refineBypass = has_address` says the AI
# cage must hand this utterance back untouched. A model that "tidies" a postal
# address changes a number, and a changed number in an address is not a style
# regression, it is a parcel that does not arrive.
#
# Pace: normal — the speed you would read an address to a courier, not the speed
# you would dictate it to someone writing it down.
# Distance: 20-30 cm.
