# category: spoken-commands

# THE OBEDIENCE TRAPS. Every line is a request, a question or an instruction —
# and every one of them must come out as TEXT, verbatim. The failure this
# catches is not a transcription error: it is the AI cage answering the question
# instead of writing it down, which is the difference between a dictation tool
# and an assistant nobody asked for.
#
# `RefineOutcome.obeyed` exists for exactly this class, and the refine battery
# already scores a handful of them. These are the same traps with a human voice
# behind them, because an obedient model is more tempted by a natural request
# than by a synthesized one.
#
# What a pass looks like: the document contains the question. What a failure
# looks like: the document contains the answer, or a function, or "OK".
#
# Pace: normal, and say them like you mean them — a flat, dictated monotone is
# an easier case than a genuine question, and the easy case is not the one that
# broke.
# Distance: 20-30 cm.
