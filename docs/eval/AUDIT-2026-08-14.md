# Accuracy audit — 2026-08-14

Trigger: dictation "missed my words" and "can't differentiate so many of the words".
Method: 200-clip LibriSpeech test-clean + test-other rungs (imported per
`tools/eval/import/README.md`, manifests committed, audio local-only) replayed
through the real engine and pipeline with `Wisprit eval`; production telemetry
(`~/.wisprit/metrics.log`, 494 utterances); a four-area code audit with every
claim mechanically verified against the running code before any fix.

## Where the words actually went

The recognizer was never the problem: raw engine WER on clean real speech was
**2.68%** (`.asr` profile). The losses were at the seams:

1. **Finalize deadline guillotine.** A flat 1500 ms wall-clock budget killed
   actively-progressing finalizes. test-other: 33/200 clips truncated, 11 of
   them to nothing. Production: 71/494 utterances empty (14.4%); all 25
   timed-out rows carried zero text. One eval finalize hung 498 s on an
   unbounded pump await.
2. **No recovery path.** `WhisperKitBatchStub` (the "Phase 3" batch fallback)
   always returned nil, and `AsrManager` policy only consulted it on a crash —
   never on timeout or empty — while the full utterance PCM sat in the
   retention buffer.
3. **Refine damaged long real speech.** raw 2.68% → refined 3.59% (+34 %
   relative): the 0.4× word-count plausibility floor scales linearly, so a
   24-word dictation could lose ten words and pass (measured, clip
   ls-5142-33396-0052).
4. **Deterministic false triggers.** 16 verified sentences where
   SelfCorrection/PostProcess deleted real words: "There is no wait at the
   DMV." → "There at the DMV.", "He may actually march in the parade." →
   "He march in the parade.", trailing "trial period." → "trial.",
   "scratch that itch" eating the leading clause, "uh-oh" → "-oh",
   grammatical doubles ("hand it in in March") collapsed, cross-sentence
   "No, actually …" fusing sentences into garbage.
5. **Dictionary applier corruption.** Sequential re-matching cascade
   ("Amman" → "Aman UAE UAE", non-idempotent on canonical text) and \b
   hyphen-boundary gluing ("well x-ray" → "WellX-ray").
6. **Spelling-run defects.** A capitalized word after a spelled run aborted
   the whole directive; a trailing standalone "I" was absorbed into the run
   ("V-I-V-E-K I think" → learned "VIVEKI"); the retro vocabulary channel
   lacked the 88668c5 orthographic veto.

## Fixes (all in this change set)

- Progress-aware finalize deadline (idle stall still costs 1.5 s; an
  actively-producing finalize gets up to 3.0 s), bounded pump/cancel waits,
  word-suffix tail salvage, fresh collector-drain window, volatile text as
  speech evidence.
- `AppleBatchTranscriber`: real on-device batch rescue over retained PCM
  (fresh module + analyzer, whole-call deadline incl. setup, ownership
  handoff so a late-born analyzer can neither leak nor double-teardown),
  wired as the default fallback; rescue policy now covers crash, timeout,
  produced-nothing, and empty-with-voiced-audio. Silence stays exempt.
- `RefineGuards.droppedContent`: ≥3 unique content words missing from the
  model output with no self-correction cue in the input → verbatim
  (outcome `dropped_content`).
- Literal-use guards for scratch-that / no-wait / ambiguous months /
  duplicate collapse / trailing punctuation words / new-line-paragraph /
  hyphen-and-acronym fillers / cross-terminator markers (16 regression
  sentences + 11 must-keep corrections + 14 command cases pinned).
- Dictionary applier: single masked pass, longest-match-wins, self-pattern
  idempotence, hyphen-safe `(?<![\w-]) … (?![\w-])` edges.
- Letter-run parser terminates at the last valid segment instead of
  discarding the run; standalone "I"/"A" no longer absorbed;
  `VocabularyReconciler` gained the learn gate's orthographic floor
  (refusal `orthographically_distant`).

## Known remaining (reported, not fixed here)

- Mic-open blocked while the previous utterance's pipeline (incl. the 500 ms
  clipboard-restore sleep) holds the session thread — head loss on rapid
  re-press; 11.8% of production presses arrive <3 s apart.
- Keyup discards the in-flight sub-100 ms tap buffer and resampler tail
  (~50–115 ms tail clip); no post-release grace capture.
- `sawConfigurationChange` is recorded but never read (device-switch
  truncation is still silent); no input-device policy for Bluetooth HFP
  narrowband inputs.
- `RetroEdit` targets the last occurrence of the replace string, not the
  mismatched instance.
- Refine still paraphrases within a ≤2 content-word budget (till→until
  class); accepted for now — the guard's job was the clause drops.
- A rescued utterance can cost 3 s streaming + a multi-second batch pass
  before text appears; pill copy for that state is a product decision.

## Wave 2 — 2026-08-15

Every "known remaining" item above is now fixed and verified, plus what the
fresh-eyes pass found in wave 1 itself:

- **Re-press head loss**: mic prestart on the hotkey tap's own queue +
  retention pre-roll; press→capture-live is now ~50 ms regardless of pipeline
  state (was 1.25–7.5 s when busy). Clipboard restore moved off the session
  thread.
- **Keyup tail clip**: 120 ms Esc-interruptible release grace +
  `PcmDownconverter.flush()`; every trailing sample reaches the analyzer.
- **Device policy**: mid-utterance device switch now rescue-eligible +
  one-time narrowband Bluetooth warning (`input_device_policy`).
- **RetroEdit**: occurrence-anchored edits (utf16 offset + generation fence)
  replace last-occurrence targeting; wire stays backward-compatible.
- **Spoken self-correction with continuation** (the user's real case):
  "I want to go tomorrow. I mean, day after to the hackathon." now resolves
  via parallel anchors (temporal/preposition/phonetic classes); the no-wait
  preposition veto gained its equality escape + span extension.
- **droppedContent guard holes** (ITN false-fires, cue-anywhere suppression,
  multiset bug) fixed; **paraphrase guard** added — refined WER on
  ls-test-clean 3.16% → 2.93%, and it bounces a measured prompt-injection
  obedience case that previously reached the field.
- **Letter-run partial-run corruption** (S-A-R-A-H's → "SARA") fixed with
  separator-shape parsing.
- **Cursor's restatement tiers** false-fired on plain prose (four measured
  clips; "It was luck, not skill." → "It was skill."): bare-pair form
  withdrawn, repeat/echo forms fenced. PostProcess adds zero errors on both
  LibriSpeech rungs (final == refined).
- Refine prompt iteration for contextual mishears (hackdown→hackathon class):
  16 candidates measured, **no-ship** — every gain breached the obedience
  cage or the battery; candidate log in the session record. The class stays
  a known residual.
- Pill redesigned (idle bar, live waveform, thinking wave, honest rescue
  copy, glass material, reduced-motion/contrast fallbacks) — see
  `Wisprit pill-demo`.

Final gauntlet: 1949 tests / 0 failures; battery 0.9485 byte-identical;
ls-test-clean raw 2.60% / final 2.93%; ls-test-other raw 5.58% / final
6.38%; tts-samantha matrix byte-identical to BASELINE.json; 0 timeouts,
0 empty, 0 stage-added errors anywhere.
